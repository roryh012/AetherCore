# AMD rendering compatibility

Local verification on 2026-10-14: Radeon RX 6900 XT, Vulkan 1.4.315,
driverInfo 26.8.1. These changes are on the local `terrain-prototype` branch.

## Observed failures and workarounds

- Host image copy is unavailable. Texture/font uploads use the existing optional
  host-copy fast path or a blocking staging-buffer fallback.
- The driver crashed compiling the multi-frustum culling shader's byte-pointer
  output arithmetic. Typed uint stores avoid that compiler failure.
- A skybox fragment BDA read caused device loss even in an otherwise empty scene.
  A constant fragment and vertex-stage reads survived. Independently compiling
  vertex/fragment modules avoided the failure; the same treatment is applied to
  built-in shaders with `fragmentMain`. Original shader algorithms remain intact.
- Recreating the histogram compute shader during viewport resize crashed inside
  the AMD driver. Its extent-independent shader handle is transferred to the new
  post-process stack; output buffers and viewport images are still recreated.

Built-in split modules are generated by CMake and included in `engine.pak`.
The factory prefers `.vert.spv`/`.frag.spv` siblings for the corresponding default
entry points. Rebuild built-in shaders with CMake; changing a loose `.spv` does not
change the packed shader loaded by the editor. Project shader hot reload still
uses its existing compiler path.

## Verification

The As Above So Below terrain scene renders with validation enabled and normal
implicit overlay settings. Its CPU geometry checks, native collider checks and
live initial/dig/add/boundary/clear/restore raycasts pass. This verifies the small
prototype on this GPU; it does not certify other GPUs, every rendering feature,
streaming performance, or a published game.

## Process-local diagnosis

- `AETHER_RENDER_DIAGNOSTIC=clear`: render only a swapchain clear.
- `AETHER_RENDER_DIAGNOSTIC=no-overlay`: omit the editor overlay submission.
- `AETHER_DIAGNOSTIC_PASSES`: comma-separated render pass names to execute;
  `none` skips pass bodies. This deliberately changes the rendered frame and is
  for isolation, not normal play.

Unset those variables for acceptance tests. Submit/present device loss now invokes
the existing diagnostic fault report before termination. Initializing the shared
push range removes the uninitialized-range warning; that warning was not the
cause of the observed skybox fault.
